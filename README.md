# IBM Applied Data Science Capstone — SpaceX Falcon 9 Landing Prediction

Course project analyzing the predictability of Falcon 9 first-stage landing outcomes using launch records, exploratory analysis, SQL, maps, dashboard visualizations, and machine learning.

## Project files

| File | Purpose |
| --- | --- |
| `01_data_collection_api.ipynb` | SpaceX API data collection |
| `02_web_scraping.ipynb` | Wikipedia launch-record scraping |
| `03_data_wrangling.ipynb` | Data preparation and landing outcome labeling |
| `04_eda_sql.ipynb` | SQL-based exploratory analysis |
| `05_eda_visualization.ipynb` | Exploratory charts |
| `06_folium_maps.ipynb` | Launch location and proximity visualization |
| `07_machine_learning.ipynb` | Classification models and evaluation |
| `08_spacex_dash_app.py` | Plotly Dash interactive dashboard |
| `08_dash_lab_instructions.md` | IBM lab instructions |

## Reproducibility status
